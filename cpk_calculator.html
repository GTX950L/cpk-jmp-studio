🔧 反向生成测试数据（按目标 Cpk 造数据）
按「目标 Cpk → σ」反推：σ = 中心到最近规格距离 ÷ (3×Cpk)，生成接近目标的正态数据（实际 Cpk 因随机波动与目标略有偏差）。双侧规格均值可留空自动取中点；单侧规格请填均值 μ。

2 规格限与参数

⚠ 规格限 LSL / USL = 图纸、客户或标准规定的合格范围（如轴径 10±0.02 → LSL 9.980 / USL 10.020），不是这批数据的最大 / 最小值。
留空会自动预填「均值 ± 3σ」——那只是试算占位值，正式判级请务必按实际规格限填写。
📈 控制限 UCL / LCL（结果区 ⑦⑧）＝ 过程数据的均值 ± 3σ，由工具自动计算、随数据波动动态变化，用于判断过程是否统计受控（识别特殊原因异常）。它与规格限是两套不同的线（控制限判受控、规格限判合格），四场景对比判定见结果区 ⑧。
图纸/客户要求的标称值（如 φ20 +0.1/-0.05 → T=20.00，非中点 20.025），仅用于 Cpm。
每行一个单点数据 → 填 0（用移动极差法算组内 σ）；若每批同时测了 n 个、记录成一组 → 填 n（n≤10 用子组极差法 Xbar-R，n>10 自动切换标准差法 Xbar-S）。

· 取消勾选某一侧规格，即切换为单侧能力分析。

⑤ 能力箱线图（观测值相对规格限的位置）
▦ 箱 = Q1~Q3（中间 50% 数据）　─ 中位数　● μ 均值　— 须 = 最小~最大　 绿区  = 规格带 LSL~USL。箱体全部落在绿区内且有余量 = 过程合格；箱体顶到/越过规格线 = 超规风险高。
⑥ 正态概率图（Quantile Plot，检验正态性）
横轴 = 理论正态分位数 z（标准正态分布的分位点，如 0=均值、±1.96=95% 边界）；纵轴 = 样本测量值。点越接近直线，数据越接近正态；右上角 R² = 拟合优度（>0.95 视为近似正态，正态能力法才可靠）。
⑦ 控制图（I-MR / Xbar-R / Xbar-S，过程稳定性判断）
主图看中心稳定性（均值漂移），辅助图看波动稳定性（离散度变化）——两张须同时看：主图越界=均值异常，辅助图越界=波动异常。
