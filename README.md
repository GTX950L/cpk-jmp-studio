# Cpk-JMP Studio

> 🟢 **直接使用**：在线打开 👉 **[cpk_calculator.html（点击运行）](https://gtx950l.github.io/cpk-jmp-studio/cpk_calculator.html)**，或[下载本地文件](https://github.com/GTX950L/cpk-jmp-studio/blob/main/cpk_calculator.html)双击用浏览器打开 —— **无需安装、无需联网、数据不出本机**，粘贴数据就能算 Cpk 并出图。
>
> 🔗 项目仓库：[github.com/GTX950L/cpk-jmp-studio](https://github.com/GTX950L/cpk-jmp-studio)

一个模仿 **JMP**「Process Capability（过程能力分析）」体验的轻量工具：给出测量数据与规格限 → 一键得到 Cp / Cpk / Pp / Ppk / Cpm 等能力指数，并自动绘制直方图、能力箱线图、正态概率图。

整个工具就是**一个自包含的 HTML 文件**（`cpk_calculator.html`），计算与绘图全部由 JavaScript 实现，**零依赖、零安装、完全离线**。

## ✨ 功能特性

- **完整 JMP 式能力分析**
  - 区分「组内 sigma（Cpk）」与「整体 sigma（Ppk）」，与 JMP 一致
  - 指数：Cp、Cpk、Pp、Ppk、Cpm、双侧/单侧，另拆分列出 Cpl、Cpu、Ppl、Ppu
  - **每个能力指数的 95% 置信区间**（下限/上限，近似公式）
  - **稳定性指标**（总 σ ÷ 组内 σ，>1.3 提示组间漂移）
  - 目标值 T 可选输入（图纸/设计标称值），用于 Cpm 与「中心偏移 μ−T」；留空自动取规格中点
  - 理论超规 PPM（组内 & 整体）、实测超规 PPM
  - **不合格分析表**（观测 % / 期望组内 % / 期望总体 %，按低于下限/高于上限/合计分组）
  - 正态性检验（Shapiro-Francia 近似 = Q-Q 图 R²），判断能否用正态能力法
- **类 JMP 图表**
  - 直方图 + 正态拟合曲线 + 规格线（LSL / USL / Target）
  - 能力箱线图（Capability Box Plot，JMP 特有，标注 Q1 / 中位数 / Q3）
  - 正态概率图（Quantile Plot）
- **6 组内置示例循环切换**：从「能力不足（D 级）」到「接近完美（A 级）」（含均值偏移示例，演示 Cp 高 Cpk 低的经典工艺陷阱），每次点击循环下一组，规格限统一 9.950~10.050 便于直接对比
- **反向生成测试数据**：填「目标 Cpk + 规格限 + 数量 n」即可生成一组正态样本（用分层采样 + 洗牌），实际算出的 Cpk 通常与目标偏差 < 5%；单侧规格需额外填均值 μ
- **灵活数据**
  - 支持个体测量（移动极差法）与子组数据（极差法，子组 2~20）
  - 支持单侧规格（只有上限或只有下限）
  - 输入框留空时自动预填「均值 ± 3σ」为规格限
  - 自动识别单位（`10.005mm`、`9.98 mm`）、自动跳过表头行 / 说明行
  - 自动容忍千位分隔符（`10,005` → `10005`）

## 🚀 怎么用

1. **打开** `cpk_calculator.html`（在线链接或本地双击）
2. **粘贴数据** —— 从 Excel / 文本直接复制即可：**自动跳过表头/说明行、自动识别单位**（`10.005mm`、`9.98 mm` 都行），多列一起粘也会自动扁平化；也可以把 `.txt` / `.csv` 文件**直接拖进页面**
3. 粘贴即自动计算；需要时再勾选 **LSL（下限）/ USL（上限）**、填写子组大小（0 = 个体测量），可选填「目标值 T」（设计标称值，留空=取规格中点），改动规格限会实时重算
   > ⚠️ **LSL / USL 填图纸 / 客户 / 标准规定的合格范围**（如轴径 10±0.02 → 9.980 / 10.020），**不是**这批数据的最大值 / 最小值。留空会自动预填「均值 ± 3σ」仅供试算占位，**正式判级前请务必填入真实规格限**——否则 Cp / Cpk 会被严重高估
4. 得到：
   - **能力判级横幅**（A / B / C / D 级结论，按 Cpk 自动判级）
   - **JMP 式报告区**（一屏装下全部关键数据，直接截图做 PPT）：直方图（含总体/组内两条正态曲线）→ 过程汇总表（LSL / 目标 / USL / n / μ / 组内σ / 总σ / 稳定性指标）→ 组内 & 总 Sigma 能力双表（含 95% 置信区间）→ 不合格分析表（观测 % / 期望组内 % / 期望总体 %）
   - **指标卡**（Cp / Cpk / Pp / Ppk / Cpm 按能力等级自动变色）+ 样本量、均值、组内/整体 σ、实测超规 PPM
   - **三张图**：直方图 + 规格线、能力箱线图、正态概率图
5. 可一键**导出指标 CSV**（含 95%CI 与不合格分析）或**导出 PNG 报告**（图 + 全部关键表格，直接可贴进 PPT）
6. 输入内容会**自动保存在本机浏览器**（localStorage），刷新 / 重开页面数据不丢，「清空」按钮可清除记忆

## 📐 方法说明（公式）

| 指标 | 公式（双侧规格） | 说明 |
|------|----------------|------|
| 组内 sigma | `MR̄ / d2(2)`（个体）或 `R̄ / d2(n)`（子组） | 反映短期过程波动 |
| 整体 sigma | 样本标准差 `s`（ddof=1） | 反映长期总体波动 |
| Cp | `(USL−LSL) / (6σ_within)` | 潜在过程能力 |
| Cpk | `min((USL−μ)/(3σ_within), (μ−LSL)/(3σ_within))` | 考虑中心偏移的实际能力 |
| Pp | `(USL−LSL) / (6σ_overall)` | 长期潜在能力 |
| Ppk | `min((USL−μ)/(3σ_overall), (μ−LSL)/(3σ_overall))` | 长期实际能力 |
| Cpm | `(USL−LSL) / (6√(σ_overall² + (μ−T)²))` | 考虑目标偏移的能力（T 可手动输入，留空取 LSL/USL 中点） |

> 单侧规格时 Cp / Cpm 无定义（显示为 `—`），Cpk / Ppk 仍可计算对应方向。

### 能力判级（A / B / C / D）

| Cpk | 等级 | 含义 |
|-----|------|------|
| ≥ 1.67 | A 优秀 | 过程稳定且余量大，可放心生产 |
| ≥ 1.33 | B 合格 | 满足一般工业要求，维持监控 |
| ≥ 1.00 | C 边缘 | 存在风险，需加强管控 / 减小波动 |
| < 1.00 | D 不足 | 超规风险高，须立即改善 |

## ⚙️ 已知限制

- 正态性检验采用 Shapiro-Francia 近似（即 Q-Q 图 R²），非严格 Shapiro-Wilk；数据明显非正态时页面会给出提示，建议谨慎解读
- Cpm 依赖目标值 T：未填写时自动取规格中点，对称公差下等价于设计目标；非对称公差（如 φ20 +0.1/−0.05）请填入真实设计目标，否则 Cpm 会被高估
- 子组大小上限 20；子组极差法的 d2 常数已覆盖到 20
- 所有数据值相同（无波动）时无法计算能力指数，页面会明确提示
