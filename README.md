# Cpk-JMP Studio

> 🟢 **直接使用**：在线打开 👉 **[cpk_calculator.html（点击运行）](https://gtx950l.github.io/cpk-jmp-studio/cpk_calculator.html)**，或[下载本地文件](https://github.com/GTX950L/cpk-jmp-studio/blob/main/cpk_calculator.html)双击用浏览器打开 —— **无需安装、无需联网、数据不出本机**，粘贴数据就能算 Cpk 并出图。
>
> 🔗 项目仓库：[github.com/GTX950L/cpk-jmp-studio](https://github.com/GTX950L/cpk-jmp-studio)

一个模仿 **JMP**「Process Capability（过程能力分析）」体验的轻量工具：给出测量数据与规格限 → 一键得到 Cp / Cpk / Pp / Ppk / Cpm 等能力指数，并自动绘制直方图、能力箱线图、正态概率图。

整个工具就是**一个自包含的 HTML 文件**（`cpk_calculator.html`），计算与绘图全部由 JavaScript 实现，**零依赖、零安装、完全离线**。

## ✨ 功能特性

- **完整 JMP 式能力分析**
  - 区分「组内 sigma（Cpk）」与「整体 sigma（Ppk）」，与 JMP 一致
  - 指数：Cp、Cpk、Pp、Ppk、Cpm、双侧/单侧，另拆分列出 Cpl、Cpu、Ppl、Ppu
  - **每个能力指数的 95% 置信区间**（下限/上限，近似公式）
  - **稳定性指标**（总 σ ÷ 组内 σ，>1.3 提示组间漂移）
  - 目标值 T 可选输入（图纸/设计标称值），用于 Cpm 与「中心偏移 μ−T」；留空自动取规格中点
  - 理论超规 PPM（组内 & 整体）、实测超规 PPM
  - **不合格分析表**（观测 % / 期望组内 % / 期望总体 %，按低于下限/高于上限/合计分组）
  - 正态性检验（Shapiro-Francia 近似 = Q-Q 图 R²），判断能否用正态能力法
- **类 JMP 图表**
  - 直方图 + 正态拟合曲线 + 规格线（LSL / USL / Target）
  - 能力箱线图（Capability Box Plot，JMP 特有，标注 Q1 / 中位数 / Q3）
  - 正态概率图（Quantile Plot）
- **SPC 控制图与控制限（过程稳定性）**
  - 控制限 UCL / LCL / CL = 过程数据均值 ± 3σ（个体数据用 I-MR 法；子组 n≤10 用 Xbar-R 极差法、n&gt;10 自动切换 Xbar-S 标准差法）
  - 控制图与规格限叠加显示，一图看出"过程稳不稳"+"产品合不合格"
  - 受控性自动判定：越界点（±3σ）/ 连续 9 点同侧（Nelson 规则 2）/ 连续 7 点趋势（AIAG 常用判据）
  - **控制限 vs 规格限 四场景判定**（结果区 ⑧，判定口径 = 受控性 × Cpk≥1.33）：
    - **理想（受控且能力达标）**：统计受控且 Cpk≥1.33 → 稳定且能力充足
    - **受控但能力不足**：统计受控但 Cpk<1.33 → 即便稳定也会持续出超差品，需改善 Cpk
    - **能力达标但失控**：Cpk≥1.33 但过程失控 → 随时可能批量不合格，立即排查特殊原因
    - **失控且能力不足**：双重风险，必须停线改善
- **7 组内置示例循环切换**：从「能力不足（D 级）」到「接近完美（A 级）」，再到「波动突增」（演示"能力达标但失控"）；含均值偏移示例（演示 Cp 高 Cpk 低的经典工艺陷阱）。**每次点击都稳定命中四场景判定中的一个**（理想 / 受控但能力不足 / 能力达标但失控 / 失控且能力不足），规格限统一 9.950~10.050 便于直接对比
- **反向生成测试数据**：填「目标 Cpk + 规格限 + 数量 n」即可生成一组正态样本（用分层采样 + 洗牌），实际算出的 Cpk 通常与目标偏差 < 5%；单侧规格需额外填均值 μ
- **灵活数据**
  - 支持个体测量（移动极差法）与子组数据（子组 2~25：n≤10 用极差法 Xbar-R，n&gt;10 自动用标准差法 Xbar-S）
  - 支持单侧规格（只有上限或只有下限）
  - 输入框留空时自动预填「均值 ± 3σ」为规格限
  - 自动识别单位（`10.005mm`、`9.98 mm`）、自动跳过表头行 / 说明行
  - 自动容忍千位分隔符（`10,005` → `10005`）
- **📖 术语百科（内置）**

  - 每条包含：**详细释义 → 公式 → 计算过程 → 对产品的影响 → 推荐执行的行为**

## 🚀 怎么用

1. **打开** `cpk_calculator.html`（在线链接或本地双击）
2. **粘贴数据** —— 从 Excel / 文本直接复制即可：**自动跳过表头/说明行、自动识别单位**（`10.005mm`、`9.98 mm` 都行），多列一起粘会被自动合并为单一数据集（**若只需分析其中一列，请只粘贴该列**）；也可以把 `.txt` / `.csv` 文件**直接拖进页面**
3. 粘贴即自动计算；需要时再勾选 **规格下限 LSL / 规格上限 USL**、填写子组大小（0 = 个体测量），可选填「目标值 T」（设计标称值，留空=取规格中点），改动规格限会实时重算
   > ⚠️ **LSL / USL 填图纸 / 客户 / 标准规定的合格范围**（如轴径 10±0.02 → 9.980 / 10.020），**不是**这批数据的最大值 / 最小值。留空会自动预填「均值 ± 3σ」仅供试算占位，**正式判级前请务必填入真实规格限**——否则 Cp / Cpk 会被严重高估
4. 得到：
   - **能力判级横幅**（A / B / C / D 级结论，按 Cpk 自动判级）
   - **JMP 式报告区**（一屏装下全部关键数据，直接截图做 PPT）：直方图（含总体/组内两条正态曲线）→ 过程汇总表（LSL / 目标 / USL / n / μ / 组内σ / 总σ / 稳定性指标 / 控制限 UCL / LCL）→ 组内 & 总 Sigma 能力双表（含 95% 置信区间）→ 不合格分析表（观测 % / 期望组内 % / 期望总体 %）
   - **指标卡**（Cp / Cpk / Pp / Ppk / Cpm 按能力等级自动变色）+ 样本量、均值、组内/总 σ、实测超规 PPM
   - **四张图**：直方图（含组内/总体两条正态曲线）、能力箱线图、正态概率图、**控制图（⑦ I-MR / Xbar-R / Xbar-S，控制限与规格限叠加）**
   - **受控性判定**（⑦）：统计受控 / 失控 + 异常模式（越界 / 9点同侧 / 7点趋势）
   - **控制限 vs 规格限 四场景判定**（⑧）：理想 / 受控但能力不足 / 能力达标但失控 / 失控且能力不足
5. 可一键**导出指标 CSV**（含 95%CI 与不合格分析）或**导出 PNG 报告**（图 + 全部关键表格，直接可贴进 PPT）
6. 输入内容会**自动保存在本机浏览器**（localStorage），刷新 / 重开页面数据不丢，「清空」按钮可清除记忆
7. 看不懂指标？点右上角 **📖 术语百科**：所有英文简称的释义、公式、计算过程、对产品的影响和推荐做法都在里面

## 📐 方法说明（公式）

| 指标 | 公式（双侧规格） | 说明 |
|------|----------------|------|
| 组内 sigma | `MR̄ / d2(2)`（个体）；`R̄ / d2(n)`（子组 n≤10）；`S̄ / c4(n)`（子组 n&gt;10） | 反映短期过程波动 |
| 整体 sigma | 样本标准差 `s`（ddof=1） | 反映长期总体波动 |
| Cp | `(USL−LSL) / (6σ_within)` | 潜在过程能力 |
| Cpk | `min((USL−μ)/(3σ_within), (μ−LSL)/(3σ_within))` | 考虑中心偏移的实际能力 |
| Pp | `(USL−LSL) / (6σ_overall)` | 长期潜在能力 |
| Ppk | `min((USL−μ)/(3σ_overall), (μ−LSL)/(3σ_overall))` | 长期实际能力 |
| Cpm | `(USL−LSL) / (6√(σ_overall² + (μ−T)²))` | 考虑目标偏移的能力（T 可手动输入，留空取 LSL/USL 中点） |
| 控制上限 UCL | 个体：`x̄ + 2.66·MR̄`；子组 n≤10：`x̄̄ + A2·R̄`；n&gt;10：`x̄̄ + A3·S̄` | 中心线 + 3σ，由过程数据算出（动态） |
| 控制中心线 CL | 个体：`x̄`；子组：`x̄̄ = Σ组均值/k` | 控制图基准线 |
| 控制下限 LCL | 个体：`x̄ − 2.66·MR̄`；子组 n≤10：`x̄̄ − A2·R̄`；n&gt;10：`x̄̄ − A3·S̄` | 中心线 − 3σ |
| R/S 图上限 | R 图：`D4·R̄`（n=20 时 D4=1.586）；S 图：`B4·S̄`（n=20 时 B4=1.490） | 子组辅助图上控制限（个体法：MR 图 UCL = 3.267·MR̄） |
| 西格玛水平 Zst | `3×Cpk`（短期，已含中心偏移） | 组内 σ 口径的等效 sigma 水平；六西格玛惯例约 +1.5 为含长期漂移的换算水平 |
| 西格玛水平 Zlt | `3×Ppk`（长期） | 整体 σ 口径的等效 sigma 水平，含批次间漂移 |

> **控制限 vs 规格限**：控制限 UCL/LCL 是过程数据算出的 ±3σ，**随波动动态变化**，判断"过程稳不稳"（统计受控）；规格限 LSL/USL 由图纸/客户给定，**固定不变**，判断"产品合不合格"。两者无必然关系，需对比解读：结果区 ⑧ 的「四场景判定」以「受控性 × Cpk≥1.33」为准（理想 / 受控但能力不足 / 能力达标但失控 / 失控且能力不足）。

> 单侧规格时 Cp / Cpm 无定义（显示为 `—`），Cpk / Ppk 仍可计算对应方向。

### 能力判级（A / B / C / D）

| Cpk | 等级 | 含义 |
|-----|------|------|
| ≥ 1.67 | A 优秀 | 能力余量大（波动与中心偏移控制良好），可放心生产 |
| ≥ 1.33 | B 合格 | 满足一般工业要求，维持监控 |
| ≥ 1.00 | C 边缘 | 存在风险，需加强管控 / 减小波动 |
| < 1.00 | D 不足 | 超规风险高，须立即改善 |

## ⚙️ 已知限制

- 正态性检验采用 Shapiro-Francia 近似（即 Q-Q 图 R²），非严格 Shapiro-Wilk；数据明显非正态时页面会给出提示，建议谨慎解读
- Cpm 依赖目标值 T：未填写时自动取规格中点，对称公差下等价于设计目标；非对称公差（如 φ20 +0.1/−0.05）请填入真实设计目标，否则 Cpm 会被高估
- 子组大小上限 25；子组极差法 d2 常数与标准差法 c4 常数均覆盖到 25；控制图 A2/D3/D4（极差法）与 A3/B3/B4（标准差法）常数同步覆盖到 25；n&gt;10 自动切换 Xbar-S 法
- 所有数据值相同（无波动）时无法计算能力指数，页面会明确提示
- **数据请按生产/测量顺序粘贴，勿排序**：个体模式的组内 σ 用移动极差法，排序数据会严重低估波动、虚高 Cpk（页面会自动检测「疑似已排序」并警告）
- 受控性判定采用 Nelson 常用三规则（越界点 + 连续 9 点同侧 + 连续 7 点趋势）；Western Electric 完整 8 规则暂未覆盖，复杂场景建议用 Minitab / JMP 复核
- 拖拽导入仅支持 .txt / .csv / .tsv / .dat 文本文件；**.xlsx 请先在 Excel 中「另存为 → CSV」再拖入**（工具为纯前端零依赖实现，不解析二进制表格格式）
- 解析按"每行提取所有数字 + 多列扁平化"处理：含序号 / 日期 / 公差等多列表格，所有数字会被自动合并为单一数据集——**请只保留要分析的那一列**，并删除表尾的合计 / 平均等统计行，拖入后留意左上角"已解析 N 个数值"提示
